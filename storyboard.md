# Storyboard

`npm run generate` writes this file from `src/storyboard.ts`. Change that file, not this one.

Every terminal recording and the report screenshot come from Veridelta commit `1f89e05`, whose package is v0.27.0's, rendered with make demo-video and vhs v0.12.1. `public/clips/manifest.json` holds each file's tape and checksum. Each recording plays whole, as its tape typed it.
